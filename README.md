# INTO THE UNKNOWN
### Somewhere between imagination and reality

An Awwwards-inspired, immersive interactive parallax scrolling website crafted with React, TypeScript, Three.js, and procedural Web Audio.

---

## 🌟 Visual Journey & Scenes

1. **Scene I — The Beginning (Terra Origin)**
   - Gigantic moon with realistic craters, corona glow, and lunar orbital parallax.
   - Multi-layer jagged mountain silhouettes with atmospheric mist.
   - Headline: *"THE WORLD IS BIGGER THAN YOU IMAGINE."*
   - Interactive celestial embers responding to mouse cursor.

2. **Scene II — The Floating Islands (Aether Sanctuary)**
   - Suspended landmasses drifting through dawn skies with volumetric sunbeams.
   - Cascading procedural waterfalls and rising airborne mist.
   - Ancient temple spires and suspension bridge tethers.

3. **Scene III — The Cosmic Dimension (Void Horizon)**
   - Interactive 3D Three.js rotating ringed gas giant planet with glowing corona.
   - Tumbling 3D sacred geometric artifacts (Icosahedron, Octahedron, Torus).
   - 2,500+ particle starfield zooming past as the user scrolls into deep space.

4. **Scene IV — The Future City (Chronos Metropolis)**
   - Towering cyberpunk megastructure skyline with illuminated window grids.
   - High-speed aerocars and flying traffic light streaks along elevated skyways.
   - Sweeping searchlight beams, atmospheric neon precipitation, and industrial beacon lights.

5. **Scene V — The Final Destination (The Event Horizon Singularity)**
   - Interactive 3D Singularity portal gateway with multi-tier counter-rotating torus rings.
   - Swirling vortex stardust particles flowing into the central event horizon.
   - Ancient shattered monolith pathway leading into the portal.
   - Headline: *"YOUR JOURNEY DOESN'T END HERE. Reality is only the beginning."*
   - Interactive Singularity Resonance shockwave trigger and smooth return warp.

---

## 🕹️ Interactive Features

- **Multi-Layer Parallax Engine**: 5+ independently moving depth layers per scene with depth multipliers (0.1x to 1.4x) and mouse-responsive perspective tilt.
- **Inertial Custom Cursor**: Desktop cursor with spring lag, expansion rings, and contextual hover badges (`ORIGIN`, `WARP`, `BEGIN`, `INSPECT`, `SCAN`, `DRONE`, `RESTART`).
- **Procedural Web Audio Engine**: Zero-asset procedural synthesizer using the Web Audio API:
  - Dynamic sub-bass drone and modulated bandpass wind.
  - Automatic tonal frequency shifts matching each scene's mood.
  - Delicate UI hover chirps and resonant chord chimes.
- **Scene Navigator HUD**: Right-hand telemetry rail with Roman numerals (I - V), real-time depth percentage, and instant warp-to-sector functionality.
- **Cinematic Loader**: Dimensional rotating rings, status log simulator, and interactive *"ENTER THE EXPERIENCE"* gateway.
